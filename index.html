📖 WebOS 新手快速指南 (Help) ✕

1. 如何開始使用及建立帳號？

• 預設提供訪客帳戶 「User」，無需密碼。
• 輕觸螢幕向上滑動進入登入介面，選擇「User」並點擊 ➔ 箭頭即可登入。
• 登入後系統會自動彈出註冊引導視窗，輸入新名稱與密碼（必填），系統會建立帳戶並即時同步至雲端，其他 iPad 或電腦皆可見！

2. 現有預設帳戶

• User: 訪客專用（無密碼，專門引導註冊新帳戶）。
• Admin: 系統管理員（預設密碼為 J45F）。

3. 系統核心功能

• 原生觸控螢幕支援：支援 iPad 點擊圖示開啟 App、拖曳標題列及拖曳右下角自由縮放視窗。
• Windows 10 風格檔案總管：具備 Ribbon 工具列、左側本機樹狀導覽欄、階層路徑列及即時檔案操作。
• 內建 Python 3 IDE、小畫家 (Paint)、終端機 (CMD)、音樂合成器、碼錶及 WebKit MDM Bypass 瀏覽器。
• 可在「設定」中即時切換 Windows 10、macOS 15 及 Ubuntu 22 三大介面風格！

歡迎使用 WebOS Project Horizon

這是一個基於純瀏覽器環境構建的高效仿真實作業系統，完全兼容於 GitHub Pages。本系統支援 Windows 10、macOS 15 及 Ubuntu 22 三大桌面環境風格隨時切換，全系統徹底封鎖商業內購與商城付費行為。

核心架構亮點

  • 雙階段真實開機：模擬 BIOS POST 自檢程序與 Linux/NT 核心日誌急速載入。
  • 觸控螢幕原生支援：完整重構視窗驅動，支援 iPad / iPhone 手指單擊開啟圖示、順滑拖曳視窗與右下角放大縮小。
  • 真實 Windows 10 檔案總管：配備 Ribbon 選單、左側導覽欄、路徑階層列與真實目錄架構。
  • 跨裝置雲端同步：新註冊帳戶自動同步至雲端，任何其他造訪此網站的裝置皆能即時讀取。
  • 雙模式智慧瀏覽器：預設 Google 搜尋，並整合 Google Translate 代理隧道繞過 MDM 限制。

命令提示字元 (Command Prompt) 完全手冊

本系統之命令提示字元具備真實虛擬目錄樹狀結構、指令歷史紀錄 (鍵盤 ↑ / ↓ 鍵回顧) 與輸出重定向功能：

指令用法說明範例
help列出所有內建支援之指令清單與語法help
dir / ls顯示當前工作目錄的檔案清單與佔用容量dir
cd [路徑]變更當前工作目錄 (支援 .. 與 \)cd System
md [名稱]在虛擬檔案系統建立新目錄mkdir Projects
echo [內容] > [檔名]建立檔案或將文字輸出重定向至指定檔案echo WebOS > test.txt
type [檔案名]印出指定文字檔案內容type copyright.txt
del [檔案名]刪除虛擬檔案系統中的指定檔案del test.txt
color [代碼]變更色彩 (0a 亮綠, 0c 亮紅, 0f 亮白, 0e 亮黃)color 0a
cls / clear清除終端機螢幕上所有文字紀錄cls
ver顯示當前 Windows 作業系統核心版本號ver
date / time檢視當前系統日期或時間date
exit安全關閉命令提示字元視窗exit

WebKit MDM Bypass 運作原理解析

功能背景：在學校或企業設備（如配置有 MDM 限制設定檔的 iPad、Mac 或特定防火牆）上，部分外部網站可能遭到 WebKit 層級攔截封鎖。

操作流程

  1. 開啟系統內建之 Edge Browser。
  2. 點擊網址列右上方之 「MDM Proxy: OFF」 使其變為綠色 ON 狀態。
  3. 在網址列輸入目標網址（例如 wikipedia.org）並按下 Enter。

代理通道機制：

系統會自動將目標網址打包並重定向至 Google Web Translation 代理伺服器（translate.google.com/translate?...）。由於校園或企業網絡通常將 Google 網域列入安全白名單，連線請求會由 Google 伺服器代理抓取目標網頁並轉譯返回，從而繞過設備端的直接連線限制。

內建應用程式特色

  • 小畫家 (Paint)：針對 iPad 觸控螢幕進行精確座標轉換，具備畫筆、橡皮擦、筆刷粗幼調節 (1-40px)、完整調色盤以及匯出 PNG 圖檔功能。
  • Python IDE：整合 Brython 3.12 引擎，無需後端伺服器即可直接在瀏覽器本地直譯執行標準 Python 3 語法與演算法。
  • 氣象中心 (Weather)：串接 Open-Meteo 免費衛星 API，支援香港、開封 (汴京)、倫敦及即時 GPS 經緯度定位。
  • 音效合成器 (Audio Synth)：利用 HTML5 Web Audio API 本地即時產生電子音階。
  • 碼錶計時器 (Stopwatch)：精準毫秒計時、支援計圈 (Laps)。
  • 檔案總管 (VFS)：Windows 10 介面、樹狀目錄瀏覽、文字建立與實體檔案上傳轉碼儲存至 LocalStorage。
