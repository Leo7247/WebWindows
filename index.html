📖 WebOS 新手快速指南 (Help) ✕

1. 如何開始使用及建立帳號？

• 預設提供名為 「User」 的訪客帳戶，無需密碼。
• 輕觸螢幕向上滑動進入登入介面，選擇「User」並點擊 ➔ 箭頭即可登入。
• 登入後系統會自動彈出註冊介面，輸入新名稱與密碼（必填），系統便會為你建立專屬帳戶並同步至雲端，其他 iPad 或電腦瀏覽本站皆可看見！

2. 現有預設帳戶

• User: 訪客專用帳號（無密碼，僅供註冊新帳號）。
• Admin: 預設系統管理員（預設密碼為 J45F）。

3. 系統核心功能

• 支援 iPad 觸控或滑鼠拖曳視窗邊框進行自由縮放 (Resizing)。
• 內建 Python 3 IDE、小畫家 (Paint)、終端機 (CMD) 及 WebKit MDM Bypass 瀏覽器。
• 在「設定」中可即時切換 Windows 10、macOS 15 及 Ubuntu 22 介面風格！

歡迎使用 WebOS Project Horizon

這是一個具備真實視窗管理、縮放拖曳、檔案管理與純淨應用的系統。全系統完全開源無商城內購。

核心特色

  • iPad 觸控螢幕原生支援：完整整合 Pointer Events，支援手指順滑拖曳視窗與拖動右下角放大縮小。
  • 跨裝置雲端同步：新註冊帳戶自動同步至雲端，任何其他造訪此網站的裝置皆能即時讀取。
  • 雙模式智慧瀏覽器：預設 Google 搜尋，並整合 Google Translate 伺服器代理隧道繞過 MDM 限制。

命令提示字元 (CMD) 手冊

本系統之命令提示字元具備目錄結構、指令歷史紀錄 (↑ / ↓ 鍵) 與重定向輸出功能：

指令用法說明範例
help列出所有內建支援之指令清單help
dir / ls顯示當前工作目錄的檔案清單與大小dir
cd [路徑]變更當前工作目錄 (支援 .. 與 \)cd Documents
md [名稱]在虛擬檔案系統建立新目錄mkdir Projects
echo [內容] > [檔名]建立檔案或重定向文字輸出至檔案echo WebOS > test.txt
type [檔案名]印出指定文字檔案內容type README.txt
del [檔案名]刪除虛擬檔案系統中的檔案del test.txt
color [代碼]設定色彩 (0a 亮綠, 0c 亮紅, 0f 亮白, 0e 亮黃)color 0a
cls / clear清除螢幕所有文字cls
ver / date / time檢視系統版本、日期或時間ver

MDM Bypass 運作原理

在學校或企業設備（配置有 MDM 限制設定檔）上，部分網站可能遭到 WebKit 層級攔截。

點擊瀏覽器右上方之 「MDM Proxy: OFF」 使其變為綠色 ON 狀態。系統會將目標網址重定向至 Google Web Translation 代理伺服器（translate.google.com）。由於大部分校園防火牆不會封鎖 Google 服務，連線請求會由 Google 伺服器代理抓取目標網頁並轉譯返回，從而繞過設備端的連線限制。
