歡迎使用 WebOS Project Horizon

這是一個基於純瀏覽器環境構建的高效仿真實作業系統，兼容於 GitHub Pages，支援 Windows 10、macOS 15 及 Ubuntu 22 三大桌面環境風格隨時切換。

核心特色

  • 真實 BIOS POST 開機：完整開機自檢程序與多段式載入流程。
  • 完全無 IAP：所有應用程式一律開源免費，無任何商城內購干擾。
  • 本地儲存隔離 (VFS)：記事本、檔案管理員、系統設定皆自動永久儲存至 LocalStorage。

命令提示字元 (Command Prompt) 完全手冊

本系統的 CMD 支援真實的目錄切換、虛擬檔案操作與指令歷史記錄（支援鍵盤 ↑/↓ 鍵回顧）：

指令用法說明範例
help列出所有內建支援之指令清單help
dir / ls顯示當前目錄的所有檔案與詳細資訊dir
cd [路徑]切換當前工作目錄（支援 .. 及 \）cd Documents
md / mkdir [名稱]建立新的資料夾mkdir Projects
type [檔案名]印出指定文字檔案內容type Notes.txt
echo [文字] [> 檔名]輸出文字或建立覆蓋文字檔案echo Hello > test.txt
del [檔案名]刪除虛擬檔案系統內的檔案del test.txt
color [代碼]變更終端機文字顏色 (0a 亮綠, 0c 亮紅, 0f 亮白)color 0a
cls / clear清除終端機螢幕所有文字cls
ver顯示當前系統核心與版本號ver
date / time檢視當前日期或時間date
exit關閉命令提示字元視窗exit

WebKit MDM Bypass 運作原理與指引

功能背景：在學校或企業設備（如配置了 MDM 限制設定檔的 iPad 或 Mac）上，某些網站可能遭到 WebKit 層級或網絡防火牆攔截。

技術架構與操作方式

  1. 開啟系統內建之 Edge Browser。
  2. 點擊網址列右側之 「MDM Proxy: OFF」 按鈕，將其切換為 綠色 ON 狀態。
  3. 在網址列輸入目標網址（例如 wikipedia.org）並按下 Enter。

代理通道機制：

系統會自動將目標網址重定向至 Google Web Translation 代理伺服器（translate.google.com/translate?...）。由於校園網絡通常將 Google 網域列入白名單，連線請求會由 Google 伺服器代理抓取目標網頁並轉譯返回，從而繞過設備端對原始網址的直接連線封鎖。

內建應用程式指南

  • 小畫家 (Paint)：具備精確座標計算之 HTML5 Canvas，提供筆刷粗幼調整、自訂色彩選取、橡皮擦以及匯出下載 PNG 圖檔功能。
  • Python IDE：整合 Brython 3.12 引擎，無需伺服器即可在瀏覽器本地即時編譯執行標準 Python 3 語法與運算。
  • 氣象中心 (Weather)：串接 Open-Meteo 免費衛星 API，支援香港、開封 (汴京)、倫敦及即時 GPS 經緯度衛星定位。
  • 檔案總管 (VFS)：支援本地文字檔案建立與實體檔案上傳轉碼儲存。
